{% blocktrans %}1. Umumiy qoidalar{% endblocktrans %}

{% blocktrans %}Ushbu Maxfiylik siyosati "Surxondaryo: Ilm va Tafakkur" jurnali saytiga tashrif buyuruvchi va undan foydalanuvchi shaxslarning (bundan buyon "Foydalanuvchi") shaxsiy ma'lumotlarini to'plash, saqlash va ishlatish tartibini belgilaydi.{% endblocktrans %}

{% blocktrans %}2. To'planadigan ma'lumotlar{% endblocktrans %}

{% blocktrans %}Saytimiz quyidagi ma'lumotlarni to'plashi mumkin:{% endblocktrans %}

  • {% blocktrans %}Ro'yxatdan o'tish vaqtidagi ism, familiya va elektron pochta manzili{% endblocktrans %}
  • {% blocktrans %}Sайтга kirishda texnik ma'lumotlar (IP-manzil, brauzer turi){% endblocktrans %}
  • {% blocktrans %}Maqola yuborish vaqtida taqdim etilgan ma'lumotlar{% endblocktrans %}
  • {% blocktrans %}Aloqa formasida kiritilgan ma'lumotlar{% endblocktrans %}
{% blocktrans %}3. Ma'lumotlardan foydalanish{% endblocktrans %}

{% blocktrans %}To'plangan ma'lumotlar faqat quyidagi maqsadlarda ishlatiladi:{% endblocktrans %}

  • {% blocktrans %}Foydalanuvchi so'rovlarini ko'rib chiqish va javob berish{% endblocktrans %}
  • {% blocktrans %}Maqolalarni ko'rib chiqish va nashr etish jarayonini ta'minlash{% endblocktrans %}
  • {% blocktrans %}Sayt xizmatlarini takomillashtirish{% endblocktrans %}
  • {% blocktrans %}Qonunchilik talablarini bajarish{% endblocktrans %}
{% blocktrans %}4. Ma'lumotlarni uchinchi shaxslarga uzatish{% endblocktrans %}

{% blocktrans %}Sizning shaxsiy ma'lumotlaringiz qonunchilik talabi yoki sudning majburiy qarori bo'lmagan taqdirda uchinchi shaxslarga uzatilmaydi va sotilmaydi.{% endblocktrans %}

{% blocktrans %}5. Cookie fayllar{% endblocktrans %}

{% blocktrans %}Saytimiz sayt xizmatlarini to'g'ri ishlashini ta'minlash uchun cookie fayllardan foydalanadi. Siz brauzer sozlamalaringiz orqali cookie fayllarni rad etishingiz mumkin, ammo bu saytning ba'zi funksiyalarini cheklashi mumkin.{% endblocktrans %}

{% blocktrans %}6. Ma'lumotlarni himoya qilish{% endblocktrans %}

{% blocktrans %}Biz foydalanuvchilarning shaxsiy ma'lumotlarini himoya qilish uchun tegishli texnik va tashkiliy choralarni ko'ramiz. Ma'lumotlar shifrlangan tarzda saqlanadi.{% endblocktrans %}

{% blocktrans %}7. Foydalanuvchi huquqlari{% endblocktrans %}

{% blocktrans %}Foydalanuvchi quyidagi huquqlarga ega:{% endblocktrans %}

  • {% blocktrans %}O'z shaxsiy ma'lumotlarini ko'rish va to'g'rilash{% endblocktrans %}
  • {% blocktrans %}Ma'lumotlarini o'chirish talabini yuborish{% endblocktrans %}
  • {% blocktrans %}Ma'lumotlarni qayta ishlashga rozilik berishdan bosh tortish{% endblocktrans %}
{% blocktrans %}8. Siyosatga o'zgartirishlar{% endblocktrans %}

{% blocktrans %}Ushbu Maxfiylik siyosati vaqti-vaqti bilan yangilanishi mumkin. Muhim o'zgartirishlar haqida foydalanuvchilar xabardor etiladi.{% endblocktrans %}
